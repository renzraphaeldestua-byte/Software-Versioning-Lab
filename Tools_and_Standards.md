## 3 Coding Standards and Practices

**NAMING CONVENTIONS**
- Different types of variables should follow standard naming conventions.
  - Local variables should be named using camel case (e.g., localVar).
  - Global variables should start with capital letters (e.g., GlobalVar).
  - Constants should be written in all capital letters (e.g., CONST).

**INDENTATIONS**
- To make the code easier to read, proper indentation is important. Programmers should use white spaces appropriately to make the code readable.

**EXCEPTION HANDELING CONVENTIONS**
- To make debugging easier, all functions that encounter an error condition should either return a 0 or a 1.
